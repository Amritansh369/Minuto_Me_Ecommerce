# Contributing

- Never push directly to `main` or `develop`.
- Branch names: `feature/m1-auth`, `feature/m2-onboarding`, `feature/m3-storefront`, `feature/m4-dashboard`, `feature/m5-cart-orders`.
- Open a PR into `develop`; at least one teammate reviews.
- Only edit files you own (see `// Owner:` header). For shared files (`app.js`, `App.jsx`) add a single line only.
- Every Product/Order query must filter by `storeId`.
